# 公开打包范围与变更

2026-10-22 从原 OCx24_HER_CO2 项目选择 163 个文件形成公开副本，原始项目不作修改。选择时的 SHA256 记录于 [original_file_hashes.json](original_file_hashes.json)；它是整理前证据，不是当前发布文件清单。当前文件以根目录 [RELEASE_MANIFEST.json](../RELEASE_MANIFEST.json) 为准。

## 保留的原始证据

- 六份上游数据表、一份上游代码与上游 MIT 许可，均保持字节不变。
- 六份历史管理文件，包括原方案、划分、冻结锁、预测冻结记录、解封记录和停止节点。
- 原分析数据、保存预测、结果表和七张 PNG 图。
- 原始报告的科学结果、数值、方法与限制。

来源清单仅保留随包八个上游文件，下载路径改为仓库相对路径，固定版本 URL 与哈希保留。[upstream_verification.json](upstream_verification.json) 记录本次重新下载八个文件后的逐字节匹配。

## 为公开使用作出的修改

|文件|修改|不变的计算内容|
|---|---|---|
|analysis_core.py|读取历史锁文件时统一 Windows / POSIX 路径分隔符|特征、权重、模型、选参、随机种子与评价|
|build_dataset.py|CSV 输出显式采用历史 CRLF 换行|原始数据解析、配对、划分和数值|
|authorized_review.py|移除每次运行都声明新的用户授权的元数据；明确自动复查范围|来源核对与统计计算|
|evaluate_holdout.py|把本次运行标为公开重放，保留先预测后评分的顺序|模型、标签、选参和评价|
|首期计算研究报告.md|补署名、许可、版本状态；替换私有目录和未打包链接；说明固定版本与复核边界|原始分析结果与局限|

新增 `export_family_table.py` 只提取原绘图脚本中生成元素组合误差表的计算，不重新拟合。新增根目录 `reproduce.py` 在新目录编排原流程，并比较所有 130 份分析数据/结果 CSV 和 JSON。新报告 HTML 内嵌原七张图，不重绘。

未随包带入原虚拟环境、缓存、历史训练模型二进制、对话与任务资料、文献附件或其他研究项目。完整复算可重新生成模型二进制。

## 验证与版本

公开前完整重训与原保存结果的比较见 [VALIDATION.md](../VALIDATION.md)。[完整复算机器记录](full_reproduction_report.json) 中的输入指纹对应所测计算代码与数据；文档和展示文件不纳入这个计算指纹。旧记录中的本地冻结与解封时间不更新。
